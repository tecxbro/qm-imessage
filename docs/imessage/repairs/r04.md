## State transitions

`acquireDispatch` locks the parent row, requires the reserved version and exact operation ID, attempt ID, conversation, idempotency key, operation name, and payload, then writes one owner, a new fence, and a future canonical expiry. It updates the parent and every child in one transaction.

`renewDispatch`, `recordConfirmedPart`, and `complete` require the exact owner, fence, and expiry returned by the live claim. Every lease decision uses the caller's canonical injected `now`; database time is used only for observational `updated_at` recovery ordering. Renewal cannot shorten or resurrect a lease. Completion at or after expiry fails closed.

`recordConfirmedPart` also requires the current attempt, exact logical index, provider conversation, unused provider-part identity, and current child fence. The confirmed child is persisted in the parent JSON and relational child row in the same transaction. An identical confirmation is idempotent while the claim remains live; conflicts and late progress are rejected.

`expireDispatch` changes an exact expired claim to an ambiguous outcome, retains confirmed children, clears the lease columns, and prevents retry. A legacy dispatched row has no exact owner or expiry to match, so its only permitted exception is a supplied expired recovery guard whose fence matches the durable fence. That exception can only move unknown work to ambiguity; it cannot complete, confirm, or retry it.

`discoverRecoverable` returns reserved work and dispatched work with an expired or missing claim, scoped by provider, installation, and line. It uses a bounded stable `(updatedAt, conversationId, idempotencyKey)` cursor. Reads lock the parent before reading children and reject disagreement among parent columns, parent JSON, relational children, and lease-column pairing. Blank persisted owners are rejected as corrupt.

Retry behavior remains limited to durable retryable failures. It creates a new operation/attempt pair, preserves confirmed children and their original fences, and reserves only unresolved children. Ambiguous work remains reconciliation-first.
