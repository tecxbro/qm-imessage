The independent plugin package pins the published declarations inspected in WT00:

- `spectrum-ts` `12.8.0`
- `@photon-ai/advanced-imessage` `2.1.0`
- `@photon-ai/cli` `2.2.0`

The declarations show that Spectrum single-content send may return a message or `undefined`; Spectrum edit and Advanced iMessage unsend return `void`; Advanced iMessage text send returns a concrete message. Unknown post-dispatch results remain ambiguous and require reconciliation before retry.
